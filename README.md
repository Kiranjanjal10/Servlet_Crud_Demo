Servlet CRUD Demo

A simple CRUD (Create, Read, Update, Delete) web application built using Java Servlets, JSP, JDBC, and MySQL. This project demonstrates basic database operations following the MVC architecture.

Features
• Add Student
• View Students
• Update Student Details
• Delete Student
• MySQL Database Integration
• MVC Architecture

Tech Stack
• Java
• Servlets
• JSP
• JDBC
• MySQL
• Apache Tomcat
• HTML
• CSS

How to Run
1. Clone the repository.
2. Import the project into IntelliJ IDEA.
3. Configure the MySQL database.
4. Update database credentials in `DBConnection.java`.
5. Deploy the project on Apache Tomcat.
6. Open:
   http://localhost:8080/ServletCrudDemo
